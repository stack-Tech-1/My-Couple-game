# Okada Rush art: prompts for ChatGPT

Okada Rush is played upright. A Lagos road scrolls down the screen while your okada rides up it, **seen from straight above** (a bird's-eye view, like a map). Everything that sits on the road must be drawn from that view, pointing up the screen.

Do every sheet in **one new chat**, so the style stays the same. Save each result into the `game images` folder. If ChatGPT gives a file its own name, that's fine; just keep them in the order below so I can tell which is which.

## 1. Start the chat

Upload two Mama Put pictures from `game images` so ChatGPT copies the style: `Warm Cartoon Restaurant Counter Interior-1.png` and `Glossy Cartoon Trays of Fried Favorites.png`. Then paste this:

```
I'm making art for a mobile game about an okada (motorbike taxi) rider in Lagos, Nigeria. The two pictures I've uploaded show the approved style: glossy hand-painted cartoon, warm saturated colours, a clean dark-brown outline around every object, light from the top left.

The game is seen from straight above, like a map: the road runs from the bottom of the screen to the top, and every vehicle points UP the picture.

Rules for every sheet I ask for:
1. Plain flat white background.
2. A wide empty gap between items. Nothing may touch or overlap.
3. A clear dark outline all round every item.
4. No text, letters, numbers, logos or number plates anywhere.
5. No shadows on the ground under items.
6. Items of the same kind are the same size and drawn from the same angle.

Reply "ready" and wait for my first sheet.
```
