# Mama Put art: prompts for ChatGPT

Copy these into ChatGPT exactly as written. Do every batch in **one chat**, so the style stays the same throughout.

## 1. Start the chat

Upload these two pictures from the `game images` folder, so ChatGPT copies their style:
- `Nigerian Food Stall Asset Sheet-2.png`
- `Vibrant Nigerian Food Stall Asset Sheet-3.png`

Then paste this:

```
I'm making art for a mobile cooking game set in a Nigerian buka. The two pictures I've uploaded are the approved style. Every picture you make in this chat must match them exactly:
- Same glossy hand-painted cartoon style, same proportions, same warm saturated colours, same clean dark-brown outline around every object, light from the top left.
- Customers: same cartoon proportions and head size as the aunty in the pink gele (not more realistic), waist up, front view, hands visible.
- Food and kitchen items: seen from slightly above at an angle, like the jollof and stew pots.

Rules for every sheet I ask for:
1. Transparent background (a checkerboard is fine).
2. Leave a wide empty gap between items. Nothing may touch or overlap.
3. Every item gets a clear dark outline all round, even white things like rice and plates.
4. No text, letters, numbers or labels anywhere.
5. No shadows on the ground, no table or floor under items.
6. Arrange the items in a neat row or grid, the same size as each other where they're the same kind of thing.

Reply "ready" and wait for my first sheet.
```

- there's no writing anywhere;
- in the three-mood sheets, it's clearly the same person every time.
