# The other four restaurants: prompts for ChatGPT

Each area of Lagos has its own restaurant, with its own room, food, "cook first" station and upgrades. **Use the same ChatGPT chat as for Mama Put**, so the style stays the same. If that chat is gone, start a new one with the setup prompt in `chatgpt-prompts.md`, and upload the Mama Put sheets again as the style reference.

Each area has five sheets. Save them into `game images` using the file names given.

**For every area, the room needs:**
- the **back wall** with the same layout as Mama Put's: a blank signboard across the top, the middle kept plain for the customers to stand against, and a window or feature on the right;
- a **counter** in that area's style.
